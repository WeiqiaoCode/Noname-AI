## 目录分层（score/）

`score/` 已按功能域物理分层，唯一对外入口为 `score/index.js`（外部引用与打包入口均指向它）。
域归属与完整清单见 [score/_DOMAIN.md](../score/_DOMAIN.md)。

```
score/
├── index.js      唯一对外入口
├── core/         基础设施（util/logger/storage/eventBus/compat/perf/i18n/导出）
├── model/        模型与训练（features / weights / trainer / 热更新 / 模型护栏）
├── think/        认知与思考（deepThink / metaCognition / cognitiveLog / 博弈心理）
├── decision/     决策核心（engine / championStrategy / postCheck / 规划 / 收敛）
├── economy/      经济与牌序（economy / costCalc / 留牌弃牌 / 响应 / 牌堆记忆）
├── timing/       各结算时机的专项加成
├── observe/      观测与记忆（observer / 对手队友建模 / 跨局记忆 / 归档）
├── guard/        护栏与接管（allyExempt / guardRecorder / aiOverride / damageTransfer）
├── optimize/     优化器（decayOpt / delay / order / perf / endgame / shaTarget）
├── ui/           面板与 UI（panel / 各面板 / charts / report）
├── selfcheck/    自检（verifyAll / selfCheck）
└── override/     原生 AI 接管层（独立子系统）
```

## 核心数据流

### 1. 决策流程

```
AI 回合开始
    ↓
bestAction(me)
    ↓
枚举候选动作（手牌、技能、装备、结束）
    ↓
对每个动作打分：
    s = 基础分
    s *= 风险系数
    s *= 局势系数
    s += 模块加分（24+ 模块）
    s = toInt8(s)  # 统一值域
    ↓
选最高分
    ↓
执行出牌
    ↓
记录决策（trainRecordSample）
```

### 2. 训练流程

```
打一局游戏
    ↓
每次决策记录样本：
    { f: [48维特征], r: 0 }  # reward 占位
    ↓
游戏结束
    ↓
回填 reward：
    所有样本的 r = 本局最终得分
    ↓
导出 JSON（可选）
    或
本地训练（localTrainer）
    ↓
保存权重到 localStorage
    ↓
下次开局自动加载
```

## 关键模块说明

### 1. engine.js（核心）

- **位置**：`score/decision/engine.js`
- **职责**：决策引擎核心，bestAction 函数
- **大小**：~10000 行
- **关键函数**：
  - `bestAction(me)`：决策入口
  - `give(char, pts, tag)`：记分
  - `givePair(from, to, pts, tag)`：守恒记分
  - `giveVs(char, pts, tag)`：阵营记分
  - `settle()`：结算

### 2. scoreUnify.js（统一值域）

- **位置**：`score/decision/scoreUnify.js`
- **职责**：统一值域为 Int8 [-127, 127]
- **关键函数**：
  - `toInt8(raw)`：浮点转 Int8
  - `toFloat(i8)`：Int8 转浮点

### 3. features.js（特征提取）

- **位置**：`score/model/features/features.js`
- **职责**：提取 130 维特征（以 `features.js` 特征契约为准；早期文档所记 48 维为旧版）
- **特征维度**：
  - f[0..7]：手牌
  - f[8..11]：血量
  - f[12..15]：身份
  - f[16..22]：场上局势
  - f[23..27]：装备
  - f[28..31]：阶段
  - f[32..35]：动作类型
  - f[36..41]：牌名映射
  - f[42..47]：目标特征

### 4. trainExport.js（训练数据缓冲）

- **位置**：`score/model/train/trainExport.js`
- **职责**：缓冲训练样本
- **关键函数**：
  - `pushSample(features, reward, meta)`：记录样本
  - `bufferSize()`：样本数
  - `bufferClear()`：清空
  - `downloadJson()`：导出 JSON

### 5. localTrainer.js（本地训练器）

- **位置**：`score/model/train/localTrainer.js`
- **职责**：本地训练 Int8 感知机
- **参数**：
  - EPOCHS = 60
  - LR_Q = 2
  - VAL_RATIO = 0.2
- **输出**：accuracy（准确率）

### 6. weights.js（模型权重）

- **位置**：`score/model/weights/weights.js`
- **职责**：从 localStorage 加载权重
- **关键函数**：
  - `predict(features)`：预测
  - `saveLocalWeights(W, b, acc)`：保存权重
  - `reloadWeights()`：重新加载

## 数据流总结

| 阶段 | 输入 | 输出 | 模块 |
|------|------|------|------|
| 决策 | 当前局势 | 最佳动作 | engine.js + 24 模块 |
| 记分 | 动作 + 结果 | 分数 | give/givePair/giveVs |
| 特征 | 动作 + 局势 | 48 维特征 | features.js |
| 训练 | 样本 + reward | 权重 | localTrainer.js |
| 推理 | 特征 | 预测 | weights.js |

---

## 性能考虑

1. **零对象分配**：features.js 用 Float32Array/Int8Array 复用
2. **缓存**：deckMemory.js 维护缓存，避免重复遍历
3. **延迟计算**：deckPredict.js 用 1 秒缓存
4. **异步训练**：localTrainer.js 用 setTimeout 异步执行
